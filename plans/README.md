# Suna 规划

本目录只保存面向未来的长期规划，不再保留已经完成、失效或与当前实现不一致的阶段性计划。旧规划仍可通过 Git 历史查阅，但不应继续影响后续 Agent 对当前架构和未来方向的判断。

## 当前规划

- [下一代通用 Agent Runtime](next-generation-agent.md)：Suna 的长期愿景、架构原则、能力边界和演进判断。

## 文档边界

- `docs/` 记录当前已经实现并可依赖的事实。
- `plans/` 讨论未来方向、尚待验证的假设和演进原则。
- `AGENTS.md` 记录当前开发过程中必须遵守的工程规则。

规划不是功能承诺，也不是固定 Roadmap。未经真实场景验证的概念，不应提前固化为 protocol、配置、状态机或用户界面。

## 维护原则

1. 只保留仍然指导未来设计的内容；失效规划直接删除，历史交给 Git。
2. 优先记录长期成立的判断、边界和决策标准，不堆积短期任务清单。
3. 不把竞品已有功能直接当成 Suna 的方向，也不以“Agent OS”“Agent 公司”等标签替代架构分析。
4. 新能力应先证明它是通用、正交、可组合的 Runtime 原语，再进入实现设计。
5. 实现完成后，实际行为进入 `docs/`；规划文档只保留尚未完成的长期方向和仍有效的原则。
