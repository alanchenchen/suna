# 主题

本文面向想改配色的用户：如何编写、选择和分享自定义主题。主题子系统在代码里的分层、适配算法和位置见 [TUI 架构](tui.md#主题系统)。

## 快速开始

1. 在 `~/.suna/themes/` 下新建一个 `.toml` 文件，**文件名就是主题名**（`mytheme.toml` → 主题名 `mytheme`）。
2. 写入 5 个必填语义色（下面是内置 `default` 的配色，改成你想要的颜色即可）：

```toml
[colors]
accent  = "#ceb6f9"
success = "#a0cf6e"
info    = "#a7c1fa"
warning = "#e4ba7e"
error   = "#faacba"
```

3. 保存后在 TUI 里打开主题列表：欢迎页选 **配置**（或在 Chat 里输入 `/config`），进入 **通用 → 主题** 后按 `Enter`。新主题会出现在列表里，可直接切换，无需重启。

Suna 首次运行时会在该目录生成一份 `README.md`，内含完整字段说明和两套可直接复制的模板。

## 主题文件位置与命名

- 目录：`~/.suna/themes/`。Suna 启动时自动创建。
- 文件名（去掉扩展名）即主题名，列表里按名字排序。
- `default` 是内置主题的保留名。放一个 `default.toml` 只会显示为不可用，不会覆盖内置主题。
- 解析失败的主题仍会出现在列表里并标注原因，不影响其它主题，也不阻塞 Suna 启动。

## 颜色格式

只接受 `#rrggbb`，大小写不敏感。

不支持 ANSI 索引色（如 `"14"`）或颜色名。原因：ANSI 索引的真实 RGB 由终端主题决定，Suna 无法测量，也就无法计算对比度、无法做深浅适配。

## 字段

必填 5 个语义色：

| 字段 | 用途 |
|---|---|
| `accent` | 主题主色：标题、光标、spinner、logo、标签底色。最影响整体观感。 |
| `success` | agent 消息、成功状态、diff 新增行。 |
| `info` | 用户消息、输入框提示符。 |
| `warning` | 工具名、Guard 警告。 |
| `error` | 错误消息、diff 删除行。 |

可选 4 个中性色，不写则按终端背景派生（推荐不写，派生值天然与终端协调）：

| 字段 | 用途 |
|---|---|
| `text` | 正文，即用户要读的内容。 |
| `muted` | 弱化文字：帮助、描述、元信息、工具详情正文。 |
| `dim` | 装饰：分隔线、边框、字形。 |
| `surface` | 表面背景：代码块。 |

色块上的文字色（工具标签、Guard 标签）由 Suna 按背景亮度自动计算，无需也无法配置。

## 终端适配

主题只需按自己的终端写一套，不必为深色/浅色各写一份：

- 与终端背景**匹配**的一侧原样使用，一个字节都不改。
- 不匹配的一侧只调整**对比度不足**的颜色：语义色保留色相，中性色保留绝对彩度。
- 对比度基于检测到的真实终端背景计算；终端不支持查询时回退到近似基准，深浅判断仍然有效。

对比度下限按用途区分：语义色与正文 4.5，次要文字 4.0，纯装饰 2.0。

## 选择与预览

在 **配置 → 通用 → 主题** 打开主题列表（英文界面为 Config → General → Theme）：

- `↑` `↓`：移动光标即**实时预览**，不落库。
- `Enter`：应用并持久化。
- `Esc`：取消，并恢复进入列表前的主题。

内置 `default` 始终排在列表首位，可随时切回。每次打开列表都会重新扫描主题目录，因此改完 TOML 后关闭再打开即可看到，无需重启。

## 分享主题

一个主题就是一个自包含的 `.toml` 文件：没有 include、没有外部引用、颜色全部内联，因此可以直接分发。

把文件发给别人，对方放进自己的 `~/.suna/themes/` 即可使用。由于主题名由文件名决定，分发时建议用有意义的名字，例如 `tokyo-night.toml`。
